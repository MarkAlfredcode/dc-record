=== EFFICIENCY: BATCH, DON'T FAN OUT (added 2026-09-05, after a 168-turn/$7.85 run) ===
Tool-call turns are the single biggest cost driver in this unattended pipeline — every turn re-sends the whole conversation so far, so 40 individual curl/pdftotext/Read calls cost far more than one script doing all 40 in a single Bash invocation. Whenever a task needs many similar items (capped PDF downloads, paginated results), write ONE bash script — a for-loop over the ID/URL list — that fetches and processes the WHOLE batch and writes combined output to a single file, then read/grep/jq that ONE file. Don't do one Bash+Read pair per item. Reserve separate tool calls for genuinely different steps (the discovery call that produces an ID list, then one batched follow-up call for all the details) rather than repeating the same fetch pattern item-by-item. This is called out explicitly at Task 1's PDF-read caps below, but apply it anywhere else in this task you'd otherwise loop with tool calls instead of a shell loop.
Also: once you've pulled what you need out of a big API response, don't keep re-reading the raw JSON in later turns — pipe curl output straight to a file and use jq to extract just the fields you need, so a large already-consumed response isn't carried forward through every remaining turn.
